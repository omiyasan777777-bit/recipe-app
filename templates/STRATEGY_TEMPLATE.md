# Threads投稿戦略 - ペルソナ・コンセプト定義

このファイルは、Threads 投稿の「軸」を定義するドキュメントです。

**重要:** ここが明確でないと、投稿がブレ、成約率が落ちます。
最初は 1-2 時間かけて、しっかり埋めてください。

---

## 第 1 部: ペルソナ設定

### あなたの投稿を読む人は誰ですか？

**年代:**
- [ ] 18-25 歳（学生・社会人新人）
- [ ] 25-35 歳（キャリア層）
- [ ] 35-45 歳（管理職層）
- [ ] 45 歳以上

**性別:**
- [ ] 男性
- [ ] 女性
- [ ] 両方

**職業:**
（例: 会社員、フリーランス、主婦、学生、など）

**悩み（これが最重要）:**
```
[悩み 1]: ________________
（例: 朝時間がない、肌荒れが治らない、痩せられない）

[悩み 2]: ________________

[悩み 3]: ________________
```

**購買特性:**
- 月額購買額: ¥___,000 程度
- 購買頻度: 週 1 回 / 月 1-2 回 / 月 3-4 回
- 決め手: 「実体験のクチコミ」「有名人の推奨」「安さ」「品質」

**どこで情報を得ているか:**
- [ ] Instagram
- [ ] Threads
- [ ] X（Twitter）
- [ ] TikTok
- [ ] YouTube
- [ ] ブログ・note
- [ ] リアルの友人

## 第 2 部: コンセプト（方向性）

### あなたは「何を」「誰に」「なぜ」提供するのか？

**コンセプト文（1 文で）:**
```
例: 「毎日のスキンケア習慣で、自分への投資を実感させる」

あなたのコンセプト:
________________________________________________________________________________
```

**Before（悩んでいる状態）:**
```
例:
- 朝時間がない
- 肌が乾燥している
- ヘアスタイルが決まらない

あなたの顧客の Before:
1. ________________________
2. ________________________
3. ________________________
```

**How（解決方法）:**
```
例:
- スキンケアを丁寧にする
- 前夜に準備する
- いい洗い流さないトリートメント

あなたが提案する方法:
1. ________________________
2. ________________________
3. ________________________
```

**After（理想の未来）:**
```
例:
- 朝に心に余裕がある
- 肌がツルツル
- ヘアスタイルが決まる

あなたが約束する未来:
1. ________________________
2. ________________________
3. ________________________
```

## 第 3 部: 語彙・トーン

### あなたの投稿で頻出する言葉は？

**カテゴリ 1（メイン対象）の語彙:**
```
例: 美容系なら「セラム」「美容液」「肌」「保湿」「コスメ」

カテゴリ:
語彙 1: ________________________
語彙 2: ________________________
語彙 3: ________________________
語彙 4: ________________________
語彙 5: ________________________
```

**カテゴリ 2（サブ対象）の語彙:**
```
例: ヘアケア、スキンケア系なら「毎日」「習慣」「ケア」「時間」

カテゴリ:
語彙 1: ________________________
語彙 2: ________________________
語彙 3: ________________________
語彙 4: ________________________
語彙 5: ________________________
```

**トーン（口調）:**
- [ ] フレンドリー（友人同士のような）
- [ ] 専門的（専門知識がある人）
- [ ] 親切（教えてあげる感じ）
- [ ] 優雅（上品な）

**トーン例:**
```
フレンドリー: 「これ、本当に推せる〜！」
専門的: 「水分保持能が高いため、肌バリアが強化されます」
親切: 「実は○○が大事なんです」
```

## チェック時の質問

セットアップ時に、以下に答えられたら OK：

- [ ] ペルソナの「悩み」が 3 つ以上明確か
- [ ] 「Before → How → After」が一貫しているか
- [ ] 語彙が 5 個以上ある（投稿が深掘りできる）
- [ ] メインテーマが「ビジネス」「商品」ではなく「ライフスタイル」か
- [ ] 推奨商品が 3 個以上ある（投稿の多様性）

## このファイルの更新タイミング

1. **初回セットアップ時**: 最初に埋める（1-2 時間）
