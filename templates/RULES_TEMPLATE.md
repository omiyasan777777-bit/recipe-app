# Threads投稿生成ルール

このファイルは、Claude が Threads 投稿を生成する際のルールを定義します。

---

## 基本ルール

### 文字数
- **単体投稿**: 200-500 字
- **スレッド投稿**: 1 投稿あたり 200-500 字

### 投稿構成
- **1 バッチ = 10 本**
  - 単体投稿: 6-7 本
  - スレッド投稿: 3-4 本（CTA 付き）

### CTA（行動喚起）
- **スレッド投稿のみ**: 最後の■で自然に挿入
- **単体投稿**: CTA 不要（例外的に入れるのは OK）
- **PR 表記**: アフィリエイトリンク時は必須（「PR」「プロモーション」を明記）

### キーワード挿入
- 各投稿に **カテゴリ 1・2 の語彙を 2-3 個**挿入

## 高成約パターン（カスタマイズしてください）

### パターン A: 「毎日の習慣」系

**形式:**
```
[導入] ～を実感した
[展開] 実は○○が重要
[解決] このアイテムで改善
[推奨] あなたも試してみては？
```

**特徴:**
- **成約率**: 15-20%（業界平均 1-2%）
- **文字数**: 250-350 字
- **タグ**: 美容、健康、生活習慣
- **CTA**: 「毎日が大事」という流れで自然に商品紹介

**例:**
```
毎日のスキンケアがこんなに大事だったなんて！
シャンプーを変えたら、髪の広がりが治った。

朝のセットが楽になって時間に余裕が出来た。
毎日のケアって、実は肌や髪の 8 割を決めるらしい。

なら、いいものを使うべき。
このシャンプーは、毎日のケアが楽しみになる品質。

毎日のスキンケア・ヘアケアを変えたい人におすすめ。
```

---

### パターン B: 「試してみた」実体験系

**形式:**
```
[購入] ～を買ってみた
[使用] 使ってみたら
[効果] こんなに変わった
[推奨] おすすめです
```

**特徴:**
- **成約率**: 12-18%
- **文字数**: 200-300 字
- **タグ**: ファッション、コスメ、ガジェット
- **CTA**: 結果から自然に推奨

**例:**
```
春は新しいワンピースで気分リセット！

このワンピース、何回も着回しできるし、
どんなコーディネートにも合わせやすい。
値段以上の価値がある。

通勤にも、デートにも。
一枚あると、春の気分が変わる。
```

---

### パターン C: 「Why？」系（悩み解決）

**形式:**
```
[悩み] 女性あるある悩み
[原因] なぜそうなるのか
[解決] 実は○○が大事
[推奨] このアイテムで解決
```

**特徴:**
- **成約率**: 10-15%
- **文字数**: 250-400 字
- **タグ**: 共感系・教育系
- **CTA**: 解決方法から自然に商品紹介

**例:**
```
朝の時間がない問題、実は「前夜の準備」で 8 割解決できる。

前夜に
- 洋服を決める
- バッグに荷物を詰める
- ヘアケアを丁寧にする

これを毎日やると、朝がめっちゃ楽。

毎朝がバタバタなら、前夜の 15 分を意識してみて。
いいシャンプーでヘアケアを丁寧にすることで、
朝のスタイリング時間が 50% カットできた。
```

## 低成約パターン（避ける）

### ❌ 「○○方法 5 選」などのリスト型
- **成約率**: 5-8%（クリックはされるが成約しない）
- **理由**: 複数選択肢があると成約判断が遅れる

### ❌ 一般論だけで実体験がない投稿
- **成約率**: 2-5%（信頼性が低い）
- **理由**: 「自分に関係ある」という実感がない

### ❌ 「○○は危険」などのネガティブ系
- **成約率**: 1-3%（スプレッド悪い）
- **理由**: Threads のアルゴリズムがネガティブを抑制

### ❌ 商品名を直接書く
- **成約率**: 0%（投稿が削除される可能性）
- **理由**: アフィリ規約違反

---

## ハッシュタグ・絵文字ルール

### ❌ ハッシュタグは使わない
- Threads ではハッシュタグの効果が低い
- テキスト本文に語彙を入れるだけで十分

### ✅ 絵文字は使ってもいい（ただし少なく）
- 最初と最後に 1-2 個程度
- 本文内の絵文字は避ける（読みにくくなる）

**例（使わない方がいい）:**
```
朝の時間がない問題、実は「前夜の準備」で 8 割解決できる。📱✨

前夜に 👇
- 洋服を決める 👗
- バッグに荷物を詰める 💼
- ヘアケアを丁寧にする ✂️

#朝活 #時間短縮 #美容 #ヘアケア
```

**例（こっちが推奨）:**
```
朝の時間がない問題、実は「前夜の準備」で 8 割解決できる。

前夜に
- 洋服を決める
- バッグに荷物を詰める
- ヘアケアを丁寧にする

これを毎日やると、朝がめっちゃ楽。👍
```

## 注意事項

### 薬事法・景品表示法を遵守
- 「治る」「必ず効く」は NG
- 「試してみたら」という体験談形式は OK

### ステマ規制法対応
- アフィリエイトリンクには「PR」「プロモーション」を明記必須

### BAN リスク管理
- **超初期（3-4 日）はリンクを貼らない**
- リンク掲載は「固定投稿」または「プロフ」に限定
- リンクは 1 つに絞る（複数は成約率低下）

## このファイルの使い方

1. **初回セットアップ時**: このテンプレートをコピー＆カスタマイズ
2. **毎月 1 日**: 前月の成約パターンを追加
3. **投稿生成時**: このファイルが自動読み込みされ、ルールに従って生成される

**重要:** このファイルを充実させるほど、成約率が上がります！
