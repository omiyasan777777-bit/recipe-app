## STEP 3｜文体・トーン設定

**基本的な話し方**
- [ ] です・ます調（丁寧・フォーマル）
- [ ] だ・である調（断定・力強い）
- [ ] タメ口寄り（フレンドリー・親近感）
- [ ] 混合（場面によって使い分ける）

**キャラクター・ペルソナ**
```
例：「失敗続きだった私が試行錯誤して見つけた方法を伝える先輩」
→ あなたのキャラクター：
```

**文章の長さの目安**
- [ ] 短め（100〜200文字）— テンポよく読める
- [ ] 中程度（300〜500文字）— 説明を加えつつ読みやすい
- [ ] 長め（600文字〜）— 深く丁寧に解説

**絵文字の使い方**
- [ ] 積極的に使う（明るく親しみやすい印象）
- [ ] 要所だけ使う（見やすさを意識）
- [ ] ほとんど使わない（シンプル・スタイリッシュ）
