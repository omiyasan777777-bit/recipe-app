# 【購入者特典②】月初に使う「ネタ30本出し」専用テンプレート

> 毎月1日にこのテンプレートを開いて、空欄を埋めてからClaudeに投げるだけ。
> 1ヶ月分30本のネタが一気に揃います。

---

## 使い方

1. **STEP 1〜3** の項目を埋める（5〜10分）
2. **実行プロンプト** をコピーしてClaudeに貼り付ける
3. 出てきた30本のネタをスプレッドシートやNotionに保存
4. 毎日1〜2本ずつ投稿していく

---

## STEP 1｜今月の状況を整理する

**今月の月・季節**
```
例：4月（春・新生活シーズン）
→ 今月：        月（       ）
```

**今月の特別なイベント・記念日（関連するもの）**
```
例：母の日、ゴールデンウィーク、梅雨入り前
→ ①
→ ②
→ ③
```

**今月フォロワーに届けたいメッセージ（1つ）**
```
例：「忙しい時期こそ、ちょっとした工夫で楽になれる」
→ 今月のテーマメッセージ：
```

**先月うまくいった投稿ジャンル（バズった・反応よかった）**
```
→ ①
→ ②
```

**先月うまくいかなかったジャンル（反応が薄かった）**
```
→ ①
→ ②
```

## STEP 2｜今月狙うターゲット読者の状態

今月、読者はどんな状況・気持ちにいますか？

**読者の今月の悩み・課題**
```
例：新年度で忙しくて料理に時間を割けない
→ 悩み①：
→ 悩み②：
→ 悩み③：
```

**読者が今月求めていること**
```
例：すぐ使えるレシピ、疲れを癒すアイデア
→ ニーズ①：
→ ニーズ②：
```

## STEP 3｜投稿ジャンルの配分を決める

30本を以下のカテゴリに振り分けてください（合計30になるように）。

|---------|------|---------|
| ノウハウ・How to系 | 本 | |
| 体験談・ストーリー系 | 本 | |
| リスト・まとめ系（〇選） | 本 | |
| Q&A・よくある質問 | 本 | |
| 季節・トレンド系 | 本 | |
| 商品・サービス紹介 | 本 | |
| 読者との交流・質問投げかけ | 本 | |
| その他（自由） | 本 | |
| **合計** | **30本** | |

## ネタ30本出し｜実行プロンプト

以下をコピーして、自分のCLAUDE.mdと一緒にClaudeへ貼り付けてください。

```
あなたは私のSNS投稿のネタ出しを手伝うアシスタントです。
以下の条件をもとに、今月投稿する30本分のネタタイトルを考えてください。

【今月の基本情報】
・月・季節：
・今月のイベント：
・今月のテーマメッセージ：
・先月うまくいったジャンル：
・先月うまくいかなかったジャンル：

【ターゲット読者の状態】
・今月の悩み：
・今月のニーズ：

【投稿カテゴリと本数配分】
・ノウハウ・How to系：　本
・体験談・ストーリー系：　本
・リスト・まとめ系：　本
・Q&A系：　本
・季節・トレンド系：　本
・商品・サービス紹介：　本
・読者交流系：　本

【出力形式】
以下の形式で30本分出力してください：

No.01 [カテゴリ] タイトル案
No.02 [カテゴリ] タイトル案
…（30本まで）

タイトルは投稿の1行目として使えるレベルに具体的に書いてください。
抽象的なタイトルは禁止。読者が「自分のことだ」と感じる表現にしてください。
```
