# 【購入者特典③】6ヶ月収益化ロードマップ・入力フォーム

> プロンプト⑲「6ヶ月収益化ロードマップ作成」を使う前に、このフォームを埋めてください。
> 現状を整理してからプロンプトを実行することで、あなた専用の精度の高いロードマップが生成されます。

---

## このフォームの使い方

1. **PART A〜E** のすべての項目を記入する（15〜20分）
2. 記入内容を **最終プロンプト** に貼り付けてClaudeへ投げる
3. 出てきたロードマップを保存・印刷して手元に置く
4. 毎月見直して進捗を確認する
