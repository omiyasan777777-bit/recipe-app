# note 記事生成ルール

## 文字数
- 本文: 1500〜4000字
- タイトル: 20〜40字（検索されやすいキーワードを含める）

## 構成パターン（いずれかを選択）

### パターンA: 問題提起型
1. 共感できる悩みの提示（冒頭100字）
2. 結論・要点（読む理由を示す）
3. 本論（3〜5つの見出しで展開）
4. まとめ + 行動を促すCTA

### パターンB: ハウツー型
1. 「〜できる方法」タイトル
2. 対象読者の明示
3. ステップ形式の解説（番号付き見出し）
4. よくある失敗・注意点
5. まとめ

### パターンC: 体験談型
1. 結果から始める（「私は〇〇を達成した」）
2. Before（悩んでいた状態）
3. きっかけ・転機
4. やったこと（具体的に）
5. After + 読者へのメッセージ

## 見出しルール
- 見出しは `##` で統一（H2レベル）
- 1記事あたり3〜6見出し
- 見出しに数字・具体性を入れると読まれやすい

## 禁止事項
- 根拠のない断言（「絶対に稼げる」等）
- 薬事法・景品表示法に違反する表現
- アフィリエイトリンクへのPR表記なし

## タグ
- 3〜5個
- 記事内容に直結するキーワードを選ぶ
- 一般的すぎる単語（「人生」等）は避ける

## CTA（最終段落）
- 「プロフィール」または「固定記事」への誘導
- 押し売りせず、自然な流れで締める
