# TravelCopy AI - Web UI セットアップガイド

ブラウザでホテル記事を自動生成するツールです。ターミナルコマンドは不要です。

---

## 📥 セットアップ（Mac）

### 1️⃣ **必要なものをインストール**

ターミナルで以下を実行（1回だけ）：

```bash
cd ~/Desktop/recipe-app/travelcopy-ai
pip3 install --upgrade pip
pip3 install -r requirements.txt
playwright install
```

⏳ **5～10分かかります**

### 2️⃣ **Ollama をインストール**

[ollama.ai](https://ollama.ai) から Mac 版をダウンロードしてインストール。

インストール後、新しいターミナルで：

```bash
ollama serve
```

このターミナルは**ずっと起動したまま**にしておいてください。

### 3️⃣ **Web サーバーを起動**

別のターミナルで：

```bash
cd ~/Desktop/recipe-app/travelcopy-ai
python3 app.py
```

表示される：

```
╔════════════════════════════════════════╗
║     TravelCopy AI - Web Version        ║
╚════════════════════════════════════════╝

🌐 ブラウザで開いてください：
   http://localhost:5000
```

## 🎯 使い方

### **ステップ1: ブラウザを開く**

```
http://localhost:5000
```

このページが表示されます：

```
┌─────────────────────────────────┐
│  🏨 TravelCopy AI               │
│  楽天トラベルのホテルから、     │
│  AI がセールスコピーを自動生成  │
└─────────────────────────────────┘
```

### **ステップ2: ホテルの URL を入力**

例：
```
https://travel.rakuten.co.jp/hotel/147451/
```

### **ステップ3: 「生成」をクリック**

⏳ **30秒～1分待つ**

### **ステップ4: 結果を確認**

```
🏨 ホテル情報
  宿名: ○○温泉
  価格: 15,000円
  特徴: 露天風呂, Wi-Fi完備

📝 ブログ記事
  （AI が生成した1000字程度の記事）

🐦 SNS投稿
  （AI が生成した180字以内のツイート）
```

各セクションの「📋 コピー」ボタンで、生成されたテキストをコピーできます。

## ❓ よくある質問

| Q | A |
|---|---|
| **「localhost に接続できない」** | `python3 app.py` が実行されているか確認。ターミナルで `Ctrl + C` して再度実行してください |
| **「Ollama が見つからない」** | [ollama.ai](https://ollama.ai) から Mac 版をインストール |
| **「エラーが表示される」** | ターミナルの出力を確認。Ollama が起動しているか確認 |
| **「生成に時間がかかる」** | 初回は時間がかかります。1～2分待ってください |
| **「別の URL で何度も生成したい」** | フォームに新しい URL を入力して「生成」をクリック |

---

## 🛑 終了する場合

1. **ブラウザ**: タブを閉じる
2. **Web サーバー**: ターミナルで `Ctrl + C`
3. **Ollama**: ターミナルで `Ctrl + C`

## 📂 ファイル構成

生成された記事は以下に自動保存されます：

```
travelcopy-ai/
└── output/
    └── {宿名}_output.txt  ← ここに保存
```
